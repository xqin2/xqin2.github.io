# Xiang Qin — academic homepage

Public website: https://xqin2.github.io/

This repository contains only the generated public website. Editable content, templates, build tools and development history are maintained in a separate private repository.

GitHub Pages publishes the `main` branch, from `/(root)`. The `.nojekyll` file disables Jekyll processing.

Do not store credentials, unpublished research material or private information in this repository. Every file and commit here is public.

Please make content and design changes in the private source repository, rebuild, and publish the generated output rather than editing generated files directly.
